# IMIE Core

Institutional Market Intelligence Engine.

IMIE Core transforms market data into institutional-grade trading intelligence through a modular pipeline covering market data, evidence, structure, liquidity, auction context, institutional confluence, decision support, runtime execution, and health monitoring.

## Requirements

- Python 3.12 or newer
- Git
- An Alpaca account and API credentials when using the Alpaca provider
